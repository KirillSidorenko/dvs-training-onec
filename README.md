# 1С · учебный плагин

Плагин для тестового задания по поддержке AI-инструментов. Работает с учебными справочниками и документами. Проверяет исходные поля и дубли, показывает предпросмотр и выполняет пробную загрузку после обязательной проверки. Также доступны имитация входа и проверка учебного платёжного реестра. Все операции локальные и выполняются на вымышленных данных.

## Установка

Понадобятся Codex Desktop, CLI Codex и Node.js версии 20 или новее. Откройте терминал и выполните:

```sh
codex plugin marketplace add KirillSidorenko/dvs-training-onec
codex plugin add dvs-training-onec@dvs-training-onec
```

Если у вас уже установлена предыдущая версия, обновите каталог командой `codex plugin marketplace upgrade dvs-training-onec` и повторите команду установки.

Откройте новый чат Codex. Если плагин не появился, перезапустите приложение. Для задания используйте только два учебных плагина и отправление `DEMO-1042`. [Второй плагин](https://github.com/KirillSidorenko/dvs-training-logistics)
